# OMRKit Studio — Interactive Live Demo

Try **OMRKit v2.1** right in your browser:
- Click **Try Demo** in the top bar to scan & grade a realistic 5-student exam cohort in 1 second (including shadows, 90° rotation, checkmarks ✓, and HITL multi-mark review).
- Generate printable **ArUco + QR** optical answer sheets in the **Sheet Generator** tab.
- Upload any blank optical form in **Template Designer** and click **Auto-Detect Grids**.
- Scan printed forms in real time with the **Live Camera** tab (`getUserMedia`).

Source code & Python SDK (`pip install omrkit`): https://github.com/duhanguler/omr
